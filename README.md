# K Explore - Premium Event Management Platform

A modern, responsive, and interactive event management website developed as a college Web Design Project.

## 🚀 Features
* **Modern UI/UX:** Clean, intuitive, "Glassmorphism"-inspired interface.
* **Dark/Light Mode:** Integrated theme toggler using CSS variables.
* **Dynamic Event Generation:** Events are rendered dynamically via JavaScript arrays.
* **Real-time Filters:** Search by title/venue and filter by categories seamlessly.
* **Live Countdowns:** JS-based countdown timer for every upcoming event.
* **Interactive Modal:** Event details and registration without unnecessary page reloads.
* **Form Validation:** Client-side Regex validation for Emails and 10-digit Indian phone numbers.
* **Local Storage Integration:** Safely stores registration submissions in browser memory.
* **Fully Responsive:** Adapts flawlessly to desktop, tablet, and mobile viewing.

## 🛠️ Technologies Used
* **HTML5:** Semantic architecture.
* **CSS3:** Flexbox, CSS Grid, Custom Variables for theming. No external CSS frameworks used.
* **JavaScript (ES6):** Vanilla JS for DOM manipulation, timers, validation, and storage.
